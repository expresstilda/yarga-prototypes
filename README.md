Статический сайт без сборки. GitHub Pages публикует корень ветки `main`.
Все страницы, стили, скрипты, изображения и шрифты находятся в репозитории.
В формах обязательны имя, телефон и отдельное согласие. Сайт готовит заявку в браузере. Посетитель отправляет её в почтовом приложении либо копирует и отправляет в Telegram или MAX.
